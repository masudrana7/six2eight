/* ===================================================
   OVERVIEW
   =================================================== */

The Grid Section block is a powerful, flexible component for displaying
grid-based content with repeating items. Perfect for:

✓ Pricing tables / pricing grids
✓ Service offerings / feature boxes
✓ Product listings
✓ Team member showcases
✓ Timeline displays
✓ Benefits/features sections

/* ===================================================
   FEATURES
   =================================================== */

✓ Responsive grid layout (1-4 columns configurable)
✓ Repeater functionality for unlimited boxes
✓ Per-box fields: Price, Year, Short Description, Description
✓ Section-level CTA button with custom link
✓ Color customization (background & text)
✓ Live editor preview
✓ Professional typography
✓ Mobile-optimized responsive design
✓ Smooth hover effects and transitions
✓ Duplicate & delete box functionality

/* ===================================================
   BLOCK FIELDS
   =================================================== */

SECTION LEVEL FIELDS:
├── Title (text) - Main section heading
├── Button Text (text) - CTA button label
├── Button Link (URL) - Button destination URL
├── Grid Columns (1-4) - Number of columns
├── Background Color - Section background color
└── Text Color - Default text color

REPEATER FIELDS (Box Content):
├── Price (text) - e.g., "$99", "Free", "Contact"
├── Year (text) - e.g., "2024", "2023"
├── Short Description (text) - Brief headline/title
└── Description (text) - Detailed description

/* ===================================================
   HOW TO USE
   =================================================== */

1. ADD BLOCK TO PAGE
   - Open WordPress page/post editor
   - Click "+" to add block
   - Search for "Grid Section"
   - Click to add the block

2. CONFIGURE SECTION
   - Enter Section Title
   - Add Button Text
   - Add Button Link (optional)
   - Select grid columns (1-4)
   - Customize colors if needed

3. ADD BOX CONTENT
   - In sidebar "Box Content Editor" panel
   - Click "+ Add New Box" button
   - Fill in fields:
     • Price (e.g., $99)
     • Year (e.g., 2024)
     • Short Description (e.g., "Starter Plan")
     • Description (full details)
   - Click "Add New Box" to add another

4. MANAGE BOXES
   - Switch between boxes using tabs at top
   - Click "Duplicate" to copy a box
   - Click "Delete" to remove a box
   - Use sidebar to edit selected box

5. CUSTOMIZE APPEARANCE
   - Adjust grid columns with slider
   - Change colors in "Color Settings"
   - Hover preview shows actual styling

6. PUBLISH
   - Click "Publish" or "Update"
   - Block renders on frontend

MOBILE (480px and below):

/* ===================================================
   TROUBLESHOOTING
   =================================================== */

Block not appearing?
- Clear browser cache
- Ensure block is registered in functions.php
- Check browser console for errors

Styling not correct?
- Verify CSS files are loading
- Check for theme CSS conflicts
- Use browser DevTools to debug

Boxes not displaying?
- Ensure box content is filled in
- Check that at least one box exists
- Verify save.js is rendering boxes

Button not linking?
- Verify button URL format (include http://)
- Check link in save.js map function
