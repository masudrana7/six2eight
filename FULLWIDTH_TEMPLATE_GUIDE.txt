/* ===================================================
   HOW TO USE THE FULL WIDTH PAGE TEMPLATE
   =================================================== */

1. CREATE A NEW PAGE IN WORDPRESS
   - Go to WordPress Admin Dashboard
   - Navigate to Pages → Add New
   - Enter your page title and content
   - Scroll down to find the "Page Attributes" section

2. SELECT THE FULL WIDTH TEMPLATE
   - Look for the "Template" dropdown in "Page Attributes"
   - Select "Full Width"
   - Click "Publish" or "Save Draft"

3. YOUR PAGE IS NOW FULL WIDTH!
   - The page will display without a sidebar
   - Content extends to the full viewport width (with max-width constraints for readability)
   - Featured image displays as a hero section

/* ===================================================
   CUSTOMIZATION GUIDE
   =================================================== */

TO CHANGE COLOR SCHEME:
Edit style.css, update CSS variables in :root
--color-primary: #00B98B;
--color-secondary: #008B6F;
--color-heading: #2D2D34;
etc.

TO CHANGE FONTS:
Edit style.css, update font imports and variables
@import url('https://fonts.googleapis.com/css2?family=YourFont:wght@400;700');
--font-family: 'Your Font', sans-serif;

TO ADJUST PADDING:
Edit .full-width-header, .full-width-entry-content
padding: 60px 40px; /* Change as needed */

TO MODIFY HEADING SIZES:
Edit .full-width-entry-content h1, h2, h3, etc.
font-size: adjust to your preference;
line-height: maintain 1.2 ratio for readability
