# ⚡ Elementor Custom Fonts - Quick Reference

## 🎯 Quick Access

**Your custom fonts in Elementor:**
- ✅ **PP Editorial Old** (weights: 300, 400, 900)
- ✅ **Inter Tight** (weights: 400, 500, 600, 700)

---

## 📌 How to Use (3 Steps)

### Step 1: Open Elementor Editor
- Click "Edit with Elementor" on any page

### Step 2: Add/Select Element
- Add heading, text, or any widget
- Click the element to select it

### Step 3: Apply Font
- **Right Panel** → **Style Tab**
- **Typography** section
- **Font Family** dropdown
- Select **PP Editorial Old** or **Inter Tight**

## 📱 Mobile Responsive Tips

1. **Test on all devices**
   - Desktop: Full size works
   - Tablet: Reduce size by 10-20%
   - Mobile: Reduce size by 30-50%

2. **Use Elementor Responsive**
   - Click device icon (desktop/tablet/mobile)
   - Adjust font size for each breakpoint
   - Preview in real-time

3. **Readability First**
   - Minimum 16px for body text
   - Minimum 24px for headings on mobile
   - Good line height (1.4-1.6 for body)

## 🎓 Pro Tips

### Tip 1: Use CSS Classes
```
In Elementor:
Element → Advanced → CSS Classes

Add any of these:
  font-secondary        (PP Editorial Old)
  font-weight-300       (Light)
  font-weight-400       (Normal)
  font-weight-600       (Semi-bold)
  font-weight-700       (Bold)
  font-weight-900       (Ultra-bold)
```

### Tip 2: Create Presets
1. Style an element perfectly
2. Save as custom style
3. Reuse across pages

### Tip 3: Consistency
- Use same fonts across site
- Limit to 2 font families
- Keep weight variations minimal

### Tip 4: Performance
- Local fonts (PP Editorial) = fast
- Google fonts cached
- Overall: < 50KB total

---

## ❌ Avoid

- ❌ Using 4+ different fonts
- ❌ Custom fonts for large body text
- ❌ Tiny font sizes (< 14px body)
- ❌ Too many font weights (limit to 2-3)
- ❌ Forgetting mobile responsive

---

## 🔧 Troubleshooting

| Problem | Solution |
|---------|----------|
| Font not showing | Hard refresh (Ctrl+Shift+R) |
| Font looks wrong | Check font weight selection |
| Performance slow | Reduce number of font variations |
| Mobile looks bad | Use responsive font sizing |
| Font keeps reverting | Check theme conflicts |
