## 💻 How It Works in CSS

```css
:root {
  --color-primary: #00B98B;      /* Primary color */
  --color-secondary: #008B6F;    /* Hover/secondary */
}

/* All these now use the new teal color */
a {
  color: var(--color-primary);   /* Links in teal */
}

a:hover {
  color: var(--color-secondary); /* Darker teal on hover */
}

.button {
  background-color: var(--color-primary);
}

.button:hover {
  background-color: var(--color-secondary);
}
```
