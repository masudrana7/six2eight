# Six2Eight WordPress Theme

A basic, responsive WordPress theme built from scratch.

## Features

- **Responsive Design**: Mobile-first approach with media queries for optimal display on all devices
- **Custom Menus**: Support for primary and footer navigation menus
- **Widgets**: Sidebar and footer widget areas for maximum customization
- **Custom Logo**: Support for custom site logo
- **Post Thumbnails**: Featured image support for posts
- **Comments**: Full comment functionality with comment form
- **Search Functionality**: Search template for finding content
- **Clean Code**: Follows WordPress coding standards and best practices

## Installation

1. Download or upload the `six2eight` theme to `/wp-content/themes/`
2. Log in to WordPress admin
3. Go to Appearance > Themes
4. Find "six2eight" and click Activate

## Customization

### Adding a Menu

1. Go to Appearance > Menus
2. Create a new menu
3. Add menu items
4. Under "Display location", check "Primary Menu" or "Footer Menu"
5. Save the menu

### Adding Widgets

1. Go to Appearance > Widgets
2. Add widgets to "Sidebar" or "Footer Widget Area"
3. Configure as needed

### Changing Colors and Fonts

Edit the `style.css` file to customize:
- Colors
- Typography
- Spacing
- Layout

## Theme Files

- `style.css` - Main stylesheet and theme metadata
- `functions.php` - Theme setup and enhancements
- `index.php` - Main template file
- `header.php` - Header template
- `footer.php` - Footer template
- `sidebar.php` - Sidebar template
- `search.php` - Search results template
- `comments.php` - Comments template
- `template-parts/content.php` - Post content template
- `template-parts/content-singular.php` - Single post/page template
- `template-parts/content-none.php` - No content found template
- `js/navigation.js` - Navigation script
